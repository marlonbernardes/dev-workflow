# Example evidence-led notes

Separate observations from hypotheses and proposals. For a test, record the
command or action, environment and observed result without secrets.

Example proposal: follow a dashboard link and return to the dashboard.
This sentence is not evidence that navigation works.

Use [[resources/templates/Investigation|Investigation template]] for structured
questions. [[investigation - template project investigation]] shows an unperformed experiment;
[[guide - example task state model]] explains why unchecked criteria cannot mean done.
