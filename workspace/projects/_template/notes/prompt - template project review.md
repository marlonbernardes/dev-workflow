# Template project review prompt

Reusable instruction example, not a record that a review occurred:

> Read this project's dashboard and actual task files. Summarize confirmed
> scope, blockers and next actions, citing the files. Flag missing evidence
> without changing statuses or marking work complete. Do not edit files or
> launch other agents.
