# Template project overview

This synthetic project demonstrates a dashboard and two deliberately unfinished
backlog tasks. Start at [[projects/_template/PROJECT|Project template]].

Keep guides, decisions, investigations and prompts together in `notes`.
Filename prefixes and note_type metadata distinguish their purpose.
Daily notes belong in the workspace's root `daily` folder only.

The task directories, not a separate database, determine task state. See
[[resources/Workspace conventions|Workspace conventions]] before moving tasks.
Reusable explanations belong in wiki; for example,
[[guide - example task state model]] describes the same state model across projects.
