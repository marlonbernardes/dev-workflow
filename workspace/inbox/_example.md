# Inbox capture example

Synthetic capture: "Investigate whether task links survive a status move."

The inbox holds unprocessed ideas, not accepted priorities. Before turning a
capture into a task or wiki note, search for existing material, clarify its
scope and link supporting evidence. This example overlaps with
[[investigation - template project investigation]]; it does not create actual investigation work.
